# 🐍 Calculadora em Python

## 📌 Sobre o projeto

Este é meu primeiro projeto desenvolvido em Python durante meus estudos de Análise e Desenvolvimento de Sistemas (ADS).

A calculadora permite realizar operações matemáticas básicas por meio de um menu interativo no terminal.

## ✨ Funcionalidades

- ➕ Soma
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- 🔁 Menu interativo com repetição de operações
- 🚫 Proteção contra divisão por zero
- ✅ Validação de opções do menu

## 🛠️ Tecnologias utilizadas

- Python 3
- Google Colab
- GitHub

## ▶️ Como executar

1. Instale o Python 3 ou abra o Google Colab.
2. Baixe ou abra o arquivo `Calculadora.py`.
3. Execute o programa.
4. Escolha a operação desejada no menu.
5. Digite os números solicitados.

## 📚 Conhecimentos praticados

- Variáveis
- Entrada e saída de dados
- Operadores matemáticos
- Estruturas condicionais (`if`, `elif` e `else`)
- Laços de repetição (`while`)
- Tratamento de divisão por zero
